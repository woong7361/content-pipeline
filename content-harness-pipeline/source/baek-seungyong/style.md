# Style — 백승용

## Summary

- Audience: 초등 저학년
- Medium: 2D 벡터 일러스트레이션. 교과서·동화풍
- Look: 굵고 깔끔한 외곽선, 플랫 셰이딩(약한 그라데이션까지 허용)
- Palette: 따뜻한 파스텔 — 하늘색, 잔디 초록, 흙 갈색, 크림 화이트 / 포인트 청·홍
- Lighting: 맑은 한낮, 부드러운 그림자. 고대비·드라마틱 조명 금지
- Line: 균일한 중간 두께 외곽선
- Rendering: 납작하고 깔끔하게. 사진실사·3D 렌더·과한 텍스처·노이즈 금지

이 요약의 출처는 `production/1-2/01/lesson.json`의 `artDirection`이다.
기억에 의존해 다시 쓰지 않고, 갱신할 일이 생기면 그 파일을 다시 읽는다.

## 이 화풍의 판별 지점

요약만으로는 갈리지 않고 **이미지를 봐야 갈리는** 것들이다. 새 asset이 이 선생님 것으로 보이는지는 여기서 결정된다.

### 외곽선이 대상마다 다르다

| 대상 | 외곽선 |
|---|---|
| 배경 | **없다.** 면과 면의 색 경계로만 형태를 만든다 |
| 캐릭터 | 짙은 갈색~검정, 균일한 중간 두께 |
| 소품·UI 표면 | 캐릭터보다 굵고, 짙은 남색 계열 |

배경에 외곽선을 넣으면 캐릭터가 배경에 파묻히고, 소품 선을 캐릭터와 같게 하면 소품이 화면에서 안 잡힌다.
**이 세 층의 선 굵기 차이가 화면의 깊이를 만든다.**

### 등신이 나이에 따라 갈린다

성인은 7~7.5등신으로 사실적이고, 어린이는 4~4.5등신 대두다.
한 화면에 성인과 아이가 함께 있으면 **키 차이가 분명히 보여야 한다.**
아이를 성인 비율로 그리거나 성인을 대두로 그리면 나이 관계가 읽히지 않는다.

### 얼굴 표현

- 눈: 큰 타원, 짙은 홍채 + 흰 하이라이트 1~2점. 어린이는 눈이 더 크고 둥글다
- 볼: 옅은 분홍 홍조 (성인·어린이 모두)
- 입: 단순한 선 하나. 감정은 눈썹 각도와 입꼬리로 낸다
- 표정은 과장하지 않는다. 놀람·당황도 웃는 얼굴의 변형 범위 안에 둔다

### 조명

광원은 항상 화면 좌상단, 맑은 한낮이다.
그림자는 대상 아래 오른쪽에 부드럽게 한 겹만 깔린다.
그림자에 외곽선을 넣지 않고, 그림자 색은 검정이 아니라 바탕색의 어두운 채도다.

### 재질

물건은 플랫한 면 + **광택 하이라이트 한 줄**로 표현한다.
금속·유리·플라스틱을 텍스처로 구분하지 않고 하이라이트의 선명도로만 구분한다.
텍스처 노이즈, 붓 자국, 종이 결을 넣지 않는다.

## Reference Priority

1. 캐릭터 identity source image
2. 같은 캐릭터의 기존 pose image
3. teacher asset reference image (`assets/`)
4. common asset reference image
5. description text

**이미지가 이 문서보다 우선한다.** 이 문서는 무엇을 볼지 알려주는 색인이다.
서술과 이미지가 충돌하면 이미지가 맞다.

## Avoid

- 배경에 외곽선을 넣는 것
- 성인과 어린이를 같은 등신으로 그리는 것
- 같은 캐릭터를 pose마다 다른 인물처럼 생성
- 고대비·역광·석양 등 드라마틱 조명
- 사진실사, 3D 렌더, 두꺼운 텍스처, 노이즈
- SVG처럼 보이는 벡터 패널, flat icon illustration, UI mockup kit
- teacher asset과 common asset의 화풍 혼합

## 이 문서를 파이프라인에 넘기는 법

`input.json`의 `metadata.style_reference_set`으로 넘긴다. 형식은 `CLAUDE.md`를 본다.
`must_follow: true`이면 **이미지에서 직접 관찰한 것이 자유로운 스타일 해석보다 우선한다.**
